# 🏦 Advanced VulnBank

A modern banking web application built with Flask for educational and training purposes.

---

## ✨ Features

- User Registration & Login
- Modern Dashboard
- Money Transfer
- Profile Management (Name, Password, Photo)
- Personal Comments
- Transaction Search
- Admin Panel
